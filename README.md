# 👾 Gameplay

## 🎮 Controls:

- Left Arrow → Move left

- Right Arrow → Move right

- Up Arrow → Shoot bullets

- ESC → Pause / Resume

- ENTER → Resume from pause or restart after game over

## 👽 Objective:

- Destroy as many UFOs as possible to earn points.

- Each UFO destroyed gives 10 points.

- Avoid colliding with UFOs; you have 3 lives.

- Game ends when all lives are lost.

## ⏸️ Pause Menu:

- Pause the game with ESC or by clicking the pause button.

- Adjust the game volume using the slider.

- Resume the game by pressing ENTER or clicking RESUME.
